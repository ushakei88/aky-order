# 아케이 올리브영 발주 대시보드

올리브원(납품확인서 R1) 발주 × SCM 재고 메일을 매칭해서, 부족 수량·카톤·유통기한 이슈를 폰으로 보는 비밀번호 대시보드.

- 화면: `index.html` (엄가네 디자인) — 데이터는 `data.enc`에 AES-256 암호화
- 계산: `build.py` (발주 vs 재고, 부족분 ÷ 입수량 = 카톤, 소비기한 1/3·미래제조·유통기한 2종 체크, 지난 확인 대비 변동)
- 재고: `fetch_stock.py` — 매일 09:40 네이버 메일에서 "아케이 품목별 재고 & 출고 현황" 최신 첨부를 받음 (Actions)
- 입력 원본은 `inputs/*.enc`로 암호화해서 보관 (`vault.py`)
- 기준표: `master.csv` (소비기한일수·입수량·프리미엄·브랜드 발주메일)

필요한 Secrets: `DASH_PW`, `NAVER_ID`, `NAVER_PW`

## 올영 손익 대시보드 (`pnl/`)
- 화면: `pnl/index.html` — 대표님용 월 매출·마진·브랜드·납품건별 손익 (가매출/실매출 표시)
- 데이터: 손익 구글시트를 엑셀로 내려받아 `pnl/build_pnl.py`로 암호화 (`pnl/data.enc`)
